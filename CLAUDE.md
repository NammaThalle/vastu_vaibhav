# Working rules for AI agents in this repository

## Git
Follow `.agents/rules/git-commits.md` exactly. It covers when to commit, simulated commit dates, identity, grouping and message style.

## Agents
Do every task in the single current agent. Do not spawn subagents, parallel agents or separate sessions unless the user approves it first.

## Writing
No emojis anywhere: code comments, docs, commit messages, PR titles and descriptions.
